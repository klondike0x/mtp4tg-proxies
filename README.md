# 🌐 MTProto Proxies Aggregator

Автообновляемый агрегатор MTProto прокси из **двух источников**:

## 📡 Источники

| Источник | Описание | Прокси |
|----------|----------|--------|
| **SoliSpirit/mtproto** | Проверенные прокси с health check из множества источников | ~200+ |
| **@mtp4tg** | Дополнительные сервера из Telegram-канала | ~10-20 |

## 📦 Форматы

| Файл | Для чего | Ссылка |
|------|----------|--------|
| [`all_proxies.txt`](./all_proxies.txt) | Скрипты, боты, импорт | [raw](./all_proxies.txt) |
| [`all_proxies.md`](./all_proxies.md) | Чтение на GitHub (кликабельные t.me ссылки) | [открыть](./all_proxies.md) |
| [`all_proxies.html`](./all_proxies.html) | Если t.me заблокирован (прямые tg:// кнопки) | [открыть](./all_proxies.html) |

## 🔄 Обновление

- **Частота:** каждые 4 часа
- **Автоматизация:** GitHub Actions
- **Файлы обновляются только при изменении данных**

## 🚀 Как использовать

### Вариант 1: Markdown (если t.me работает)
1. Откройте [`all_proxies.md`](./all_proxies.md)
2. Нажмите на ссылку нужного прокси
3. Telegram предложит подключить прокси — подтвердите

### Вариант 2: HTML (если t.me заблокирован)
1. Откройте [`all_proxies.html`](./all_proxies.html)
2. Нажмите на кнопку с нужным прокси
3. Telegram откроется автоматически

### Вариант 3: TXT (для импорта)
1. Скопируйте ссылку из [`all_proxies.txt`](./all_proxies.txt)
2. Вставьте в: Настройки → Данные и память → Прокси-сервер → Добавить прокси

## 🛡 Преимущества

- ✅ **Проверенные прокси** от SoliSpirit (health check)
- ✅ **Дополнительные сервера** из @mtp4tg
- ✅ **Независимость** — если один источник упадёт, второй продолжит работать
- ✅ **Три формата** — работает везде, даже если t.me заблокирован
- ✅ **Автообновление** каждые 4 часа

## ⚠️ Важно

- Прокси предоставляются "как есть", без гарантий
- Некоторые сервера могут перестать работать между обновлениями
- Прокси с пометкой ✓ (SoliSpirit) прошли проверку работоспособности
- Используйте на свой страх и риск
